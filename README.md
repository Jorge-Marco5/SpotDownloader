# SPOTDOWNLOADER - Rama web

Rama en la que está la interfaz web del proyecto con funciones de descarga solo de youtube.

## Requisitos

- flask
- yt-dlp
- python-dotenv

## Ejecución

```bash
source venv/bin/activate
python3 app.py
```

La página estará disponible en [http://localhost:5000](http://localhost:5000)
